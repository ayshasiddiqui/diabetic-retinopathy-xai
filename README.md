# Diabetic Retinopathy XAI

## Project Overview

An explainable deep learning-based system for diabetic retinopathy
severity grading using retinal fundus images.

The system aims to classify diabetic retinopathy into five severity levels:

- No DR
- Mild DR
- Moderate DR
- Severe DR
- Proliferative DR

## Planned Features

- Fundus image preprocessing
- Deep learning-based DR classification
- Five-class severity grading
- Explainable AI
- Grad-CAM visualization
- Retinal lesion analysis
- Model evaluation
- Confidence estimation
- Web application
- Automated report generation

## Technologies

## Dataset

This project uses the Indian Diabetic Retinopathy Image Dataset (IDRiD).

The dataset is not included in this repository.
